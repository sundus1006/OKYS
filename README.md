# OKYS - Otomatik Kütüphane Yönetim Sistemi

Bu proje, kütüphane kitaplarının ve kitap kopyalarının yönetilmesini sağlayan basit bir Otomatik Kütüphane Yönetim Sistemi'dir.

## Projede Bulunan Sınıflar

- Kitap
- KitapKopyasi
- Kullanici
- OduncKaydi

## Projenin Amacı

Kitapların, kitap kopyalarının, kullanıcıların ve ödünç alma işlemlerinin nesne yönelimli programlama kullanılarak modellenmesi amaçlanmıştır.

## Kullanılan Teknoloji

- Java
